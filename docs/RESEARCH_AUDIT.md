# Research citation audit

Reviewed 2026-10-21 against c59862b; Remaining Batch 3 only. All counts refer to existing public profile projections, not database edits.

- **54 profiles audited:** 497 source uses consolidated into 341 document entries; **156 duplicate citation displays removed**. Claims, page/table links, original map objects/revisions and attributions remain.
- **246/248 URLs reachable**, including one local permission file; **2 unresolved**. Remote checks use GET, up to 64 KiB, three simultaneous requests, batches of 12 and one retry for failures. A successful HTTP response establishes reachability, not claim validity. No 404/410 was confirmed.
- **Metadata still unavailable:** 0 titles; 10 author/organization fields (nine local permission declarations and one custom attribution license); 318 publication-year fields across profile citation entries. Most year gaps are map objects, licenses and photographs, not papers with known publication dates. Four photographic creator identities remain explicitly unidentified/unspecified in the existing credits.
- Source-check dates, plan periods, map revisions and image capture dates are retained as source context, never substituted for publication years. Generic catalogue caveats are labelled separately from source findings.
- No incorrectly assigned reference was established in the reviewed 54 profiles. Known lake-paper scope is enforced in presentation; a wrong-profile fixture is quarantined without changing stored data. Operator/property sources support qualified location/provenance only, community sources retain their stated accuracy limits, and naming/habitat references never establish local occurrence.

# AquaMap Laguna

A Laravel + MySQL GIS information system with 54 stored/public profiles: 10 lakes, 29 rivers, 13 waterfalls and two qualified spring-resort property references. The approved current batch is Remaining Batch 2 only: sourced Filipino fish names against 30a77d5; further batches require explicit approval. All stored records, scientific evidence, photographs and reviewed GIS geometry are preserved. Seventeen rivers have source-checked courses, twelve remain unmapped and whole-river totals remain unverified; see RIVER_INVENTORY.md.

The public dashboard opens directly to a compact left search/category/list sidebar and a large right Leaflet map. Desktop/tablet keep columns; mobile provides a collapsible complete sidebar. Selecting a marker, shape or list item opens one nonmodal profile with four bottom sections and an interactive map. Source/calculated measurements remain separate. Focus/click enables deliberate wheel/trackpad zoom. One fixed Report a Concern link leads to the public reporting form. No database migration or new import is needed for this redesign.

Public research distinguishes documented historical fish occurrence from unassessed habitat suitability. Water Type uses exact-identity reviewed evidence (historical freshwater context for Yambo/Pandin/Calibato); other labels remain unknown. The sole existing fish species, Nile tilapia (Oreochromis niloticus), has the SEAFDEC-sourced Filipino name Plapla in a read-only naming supplement; unsupported names remain unverified. Naming never creates occurrence links. All report details, counts, statuses and evidence are administrator-only, including query/HTML/JSON boundaries. New reports require private JPEG/PNG/WebP photo proof up to 5 MB; contacts/incident points remain optional. Historical reports without photos remain valid. No scientific pollution percentage or suitability engine exists.

Use **Pagsanjan Falls** (existing ID 6) and **Taytay Falls** (existing ID 20) as primary names everywhere. Cavinti Falls/Magdapio Falls and Majayjay Falls remain alternative names in Research & Sources and searchable aliases. Never create separate records or change their existing geographic, photo, fish or report associations for a display-name correction.

`WaterBody::PUBLIC_CATEGORIES` defines the map's lake/river/waterfall scope. `REPORT_CATEGORIES` includes Natural Springs / Spring Resorts for database-generated report choices and matching server validation. Selections and text survive errors; native selects, grouped no-JavaScript fallback and mobile layouts remain accessible. Twenty-seven photographs and 27 placeholders appear publicly, including the qualified resort references. Nine optimized Google Doc photographs are used under the project owner's explicit ownership/permission confirmation; source credits, unidentified-author labels and the permission declaration are retained. All twenty prior image files/credits remain intact. See [IMAGE_INVENTORY.md](IMAGE_INVENTORY.md).

Run `php artisan waterfalls:import --no-interaction` for only the two reviewed missing falls; it never runs migrations or overwrites existing metadata and refuses unexpected databases/alias conflicts. Full ExplorerSeeder fixture imports include the additive waterfall catalogue. Source points retain explicit photo/community-reference accuracy limits; no new fish records, environmental measurements or pollution reports were created.

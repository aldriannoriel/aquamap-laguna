# AquaMap Laguna

A Laravel + MySQL GIS information system with 55 stored/public profiles: 11 lakes, 29 rivers, 13 waterfalls and two qualified spring-resort property references. The approved crash-recovery scope adds verified Tadlac Lake, changes desktop proportions and removes the public reference library while preserving individual research tabs. Patola Lake remains withheld without a reliable location. All original records, scientific evidence, photographs and reviewed GIS geometry are preserved. Seventeen rivers have source-checked courses, twelve remain unmapped and whole-river totals remain unverified; see RIVER_INVENTORY.md.

The public dashboard opens directly to a left search/category/list sidebar and right Leaflet map, split 25%/75% at desktop widths of at least 1100 px. Tablet keeps its existing columns; mobile provides a collapsible complete sidebar. Selecting a marker, shape or list item clones its inert profile template into one nonmodal profile with four bottom sections, including Research & Sources. The public all-profile reference library is removed; underlying research remains intact. Source/calculated measurements remain separate. Focus/click enables deliberate wheel/trackpad zoom. One fixed Report a Concern link leads to the public reporting form. The additive Tadlac import requires no migration.

ResearchSources consolidates each document once per profile across six evidence groups, retaining claims, source dates/revisions, page/table links and licensing. Unknown metadata remains explicit; link reachability is recorded separately from evidence validity. The earlier 54-profile baseline and 248 URLs were audited; see RESEARCH_AUDIT.md and its machine-readable ledger. No runtime network checks or stored-data changes are introduced.

Public research distinguishes documented historical fish occurrence from unassessed habitat suitability. Water Type uses exact-identity reviewed evidence (historical freshwater context for Yambo/Pandin/Calibato); other labels remain unknown. The sole existing fish species, Nile tilapia (Oreochromis niloticus), has the SEAFDEC-sourced Filipino name Plapla in a read-only naming supplement; unsupported names remain unverified. Naming never creates occurrence links. All report details, counts, statuses and evidence are administrator-only, including query/HTML/JSON boundaries. New reports require private JPEG/PNG/WebP photo proof up to 5 MB; contacts/incident points remain optional. Historical reports without photos remain valid. No scientific pollution percentage or suitability engine exists.

Use **Pagsanjan Falls** (existing ID 6) and **Taytay Falls** (existing ID 20) as primary names everywhere. Cavinti Falls/Magdapio Falls and Majayjay Falls remain alternative names in Research & Sources and searchable aliases. Never create separate records or change their existing geographic, photo, fish or report associations for a display-name correction.

`WaterBody::PUBLIC_CATEGORIES` defines the map's lake/river/waterfall scope. `REPORT_CATEGORIES` includes Natural Springs / Spring Resorts for database-generated report choices and matching server validation. Selections and text survive errors; native selects, grouped no-JavaScript fallback and mobile layouts remain accessible. Twenty-seven photographs and 28 placeholders appear publicly, including the qualified resort references. Nine optimized Google Doc photographs are used under the project owner's explicit ownership/permission confirmation; source credits, unidentified-author labels and the permission declaration are retained. All twenty prior image files/credits remain intact. See [IMAGE_INVENTORY.md](IMAGE_INVENTORY.md).

Run `php artisan waterfalls:import --no-interaction` for only the two reviewed missing falls; it never runs migrations or overwrites existing metadata and refuses unexpected databases/alias conflicts. Full ExplorerSeeder fixture imports include the additive waterfall catalogue. Source points retain explicit photo/community-reference accuracy limits; no new fish records, environmental measurements or pollution reports were created.

Run `php artisan lakes:import --no-interaction` explicitly for the reviewed Tadlac addition. It reuses guarded transactional identity/metadata checks, rejects alias conflicts and preserves repeat-import timestamps. ExplorerSeeder's original baseline remains unchanged. Source evidence and the withheld Patola candidate are documented in RESEARCH_SOURCES.md.

- **Implemented Day 3:** sourced historical Nile tilapia aquaculture records for the three lakes, general FAO habitat information, nullable study metadata, idempotent fish seeding, and responsive fish cards integrated with map selection. Occurrence is separate from unassessed compatibility.
- **Implemented Day 4:** public reporting form at `/reports/create`, validated/throttled submissions at `POST /reports`, server-assigned pending status, optional explicit incident points, private photos/contact details and generic confirmation. Reports are not publicly readable. Existing schema and research data are unchanged.
- **Constraints:** modify only this project; persistent database work is restricted to `aquamap_laguna`. Never reset databases, expose/change credentials, or fabricate measurements, pollution reports, or habitat conclusions.
- **Implemented Day 5:** administrator-only session login, protected dashboard/counts, report search/filters/pagination/details, private evidence streaming, controlled status transitions and atomic audit history. New admin accounts require the interactive local `admin:create` command; no public registration or community accounts exist. All report data and counters stay administrator-only; the redesigned public map has no aggregate exception.
- **Implemented local anti-spam:** anonymous reports now have a hidden honeypot and an encrypted, session-bound 3-second server timer (2-hour validity). The existing 5-attempts/hour/IP limiter remains unchanged. Recent same-session lake/type repeats receive a nonblocking warning after saving privately as pending; other people's report history is never queried for warnings.
- **Implemented GIS and redesign:** reviewed geometry/catalogues, dynamic full-profile filtering, one nonmodal four-section card, private reporting, qualified resort references and preserved licensed/owner-authorized images. Details and remaining evidence gaps are in CURRENT_STATE.md, RIVER_INVENTORY.md and IMAGE_INVENTORY.md. No automatic deployment, scientific suitability engine or invented measurements are authorized.
